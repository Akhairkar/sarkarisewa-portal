Send an update

Email and Telegram are available. WhatsApp sending is disabled. Telegram has two modes: private messages to linked subscribers and broadcast posts to the SarkariSewa India channel.

Before sending

  • Use this for useful updates, not repetitive promotional messages.
  • WhatsApp sending is disabled until a proper provider/API workflow is configured.
  • Telegram Channel publishing requires the bot to be an administrator of the channel with permission to post, plus the bot token/channel settings in Supabase Edge Function Secrets.
  • Telegram DM works only when a subscriber has a linked telegram_chat_id; Channel publishing is a separate broadcast.
  • Every campaign creates a delivery record so failures can be reviewed.

Do not paste API keys into this page. Provider credentials belong in Supabase Edge Function Secrets.
