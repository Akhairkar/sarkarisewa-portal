Integration and safety notes

  • Payment table is the reporting mirror; it is not a live Razorpay dashboard.

  • No API keys, customer RC numbers, phone numbers, or full provider payloads are displayed.
  • This page does not create refunds, retry payments, change membership status, or call paid provider APIs.
  • Other API products are not shown until a documented usage table exists. No placeholder counts are invented.
