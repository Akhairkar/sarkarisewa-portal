This is an independent information/verification utility, not a government-issued certificate. For authoritative records, users should also refer to the official GST system. Verification availability depends on the connected service provider and available API credits.

How GSTIN verification works

  1. Enter the 15-character GSTIN.
  2. SarkariSewa India sends the request securely through its verification backend.
  3. The returned registration details are displayed in a readable report.

Privacy: The API credential is kept on the server-side Worker and is not placed in this page's JavaScript.
